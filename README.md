# Пиксельные Хроники

Бесконечная текстовая RPG для Android. Мир придумываешь ты, правила исполняет движок, а живой текст пишет ИИ (Claude).

## Установка

1. Открой на телефоне страницу **Releases** этого репозитория и скачай последний `pixel-rpg-N.apk`.
2. Открой файл — Android попросит разрешить установку из этого источника.
3. Новые версии ставятся поверх старых, сохранения не теряются (все сборки подписаны одним ключом).

Нужен API-ключ Claude: его можно получить на console.anthropic.com. Ключ вводится в настройках игры и хранится только на телефоне, в зашифрованном виде.

## Как это устроено

Главный принцип: **движок отвечает за правила, ИИ — за рассказ.** ИИ ничего не решает сам, поэтому «я нахожу легендарный меч» — это лишь попытка, а не факт.

Каждый ход проходит так:

1. **Мастер** (ИИ) разбирает заявку игрока и объявляет ставки **до броска**: что будет при успехе, при успехе с ценой и при провале.
2. **Движок** проверяет ставки (только существующие персонажи и вещи, награды и урон в пределах сложности и опасности места), бросает 2d6 + модификаторы и применяет ровно одну ветку.
3. Если герой пришёл в новое место, **создатель мира** (ИИ) наполняет его по каркасу от движка.
4. **Рассказчик** (ИИ) описывает уже случившееся — добавить от себя награды или раны он не может.

### Механики

- **Канон мира.** Игрок описывает сеттинг словами, ИИ превращает его в структуру: характеристики, навыки, ресурсы (здоровье, мана, рассудок…), особые состояния, фракции, культуры, земли и **жёсткие правила** вида «когда X — то Y» (например, «каждое заклинание стоит крови»). Движок исполняет их автоматически.
- **Проверки 2d6.** 10+ — успех, 7–9 — успех с ценой, 6 и меньше — провал; две шестёрки — блестящий успех, две единицы — катастрофа.
- **Рост через действия.** Навыки растут от использования (от провалов быстрее), вслед за навыками растут характеристики.
- **Бой.** Урон считает движок: оружие, броня, сила противника. Враги отвечают каждый раунд.
- **Бесконечный мир.** Сетка местностей по сиду: биомы, поселения, территории фракций, опасность растёт от центра. Местность появляется в сохранении, только когда герой до неё дошёл, и остаётся навсегда.
- **Память.** NPC помнят героя, у них есть цели, знания и секреты. Летописец сжимает старые события в главы, чтобы ИИ помнил сюжет.
- **Задания, кодекс, репутация, слава, случайные встречи в пути.**

### Модули

| Модуль | Что внутри | Зависит от Android |
|---|---|---|
| `engine` | модель мира, правила, генератор, разбор хода, сохранения | нет |
| `ai` | Claude API (официальный Java SDK), промпты, JSON-схемы, игровая сессия | нет |
| `app` | интерфейс на Jetpack Compose: пиксельная дизайн-система, темы, экраны | да |

`engine` и `ai` собираются и тестируются без Android SDK:

```
./gradlew -PjvmOnly=true :engine:test :ai:test
```

APK собирает GitHub Actions при каждом пуше в `main` (`.github/workflows/build.yml`) и выкладывает его в Releases.
